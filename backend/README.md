# E-commerce Backend API

## Project Overview

A RESTful backend API for an e-commerce application built using Node.js, Express.js, and MongoDB. The project provides user authentication, product management, shopping cart operations, order processing, checkout, and simulated payment functionality.

## Features

- User registration and login with JWT authentication
- Secure password hashing using bcryptjs
- Product CRUD operations
- Product search and filtering
- Shopping cart management
- Order and checkout management
- Simulated payment processing
- Input validation
- API rate limiting
- MongoDB database integration

## Technology Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- express-validator
- express-rate-limit
